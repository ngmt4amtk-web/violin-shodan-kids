# 仕事

私（長又）が幼稚園生向けに作るバイオリンのWebアプリ「バイオリン初段 幼稚園生版」（~/violin-shodan-kids）で使う、ごほうびと背景の絵を3枚作る。アプリには、ふわふわ（クリーム色の丸いこいぬ風キャラ）ときょうりゅう（青緑の小さな恐竜）がいる。参照画像は src/reference/fluffy-cutout-v1.png と src/reference/dino-cutout-v1.png。最初に built-in の view_image でこの2枚を開き、**線の太さ・色合い・やわらかさ・かわいさ**を確かめて、3枚とも同じ絵本風のかわいい絵柄にそろえる（太めの暖かい茶色の輪郭線、やさしいパステル、ぷっくりしたハイライト）。

出力は3枚。

## 1. src/generated/props-sheet.png（ゴールまわりの小道具6つ）

1536×1024 の1枚、**3列×2行**の6コマ（1コマ512×512）。背景は全面、緑 #00B140 のベタ塗り（コマの間も同じ）。左上から右へ、次に下の段の左から右へ、次の順に並べる。

1. 白と黒の市松模様のゴールフラッグ。細い旗ざおに付いている。
2. 虹色の飾り旗（三角の旗をつないだ紐）が上にかかった、丸いアーチ型のゴールゲート。星を1つ上に載せる。
3. 水色の三角のスタートフラッグ。細い旗ざおに付いている。
4. 赤・黄・水色の3つの風船のたば。
5. 大きな金色の星。まわりに小さなきらきら。
6. 金色のメダル。虹色のリボン付き。

小道具には**緑色を使わない**（背景のキー色と同じになるため）。

## 2. src/generated/stickers-sheet.png（ごほうびシール6枚）

1536×1024 の1枚、**3列×2行**の6コマ（1コマ512×512）。背景は全面、マゼンタ #FF00FF のベタ塗り（コマの間も同じ）。6枚とも、絵のまわりに**厚めの白いシールのふち**を付ける。ふちの外に影は付けない。ピンクや赤紫は使わない（背景のキー色に近いため。頬の赤みは薄い橙寄りにする）。左上から右へ、次に下の段の左から右へ。

1. ふわふわの白い羊（メリーさんのひつじ）。丸い毛、小さな顔。にっこり。
2. にっこり笑った金色の星。小さなきらきら付き。
3. 小さな翼のついた、赤い運動靴。足の速さを表すふんわりした雲の筋を後ろに付ける。
4. にっこり顔のバイオリン。弓が1本ななめに添えてある。
5. 金色のトロフィー。星の飾り付き。
6. 虹と、そのはしの2つの白い雲。

## 3. src/generated/scenery-meadow.png（走るコースの背景）

1536×1024 の1枚、全面に絵が入った風景（キー色の背景ではない）。昼のやさしい草原。上の半分は、淡い水色の空・ふわふわの白い雲・遠くのなだらかなパステルの丘・丸い木が数本。地平線は高さの45%あたり。下の約4割は、何も置かない広い草地（走るキャラクターを後から重ねる場所）で、草地には細かい花の点を少しだけ散らす。キャラクター・文字・数字・バイオリン・柵・道路・建物は描かない。キー色（緑のベタ塗り・マゼンタ）は使わない。

# 触ってよい範囲

- ~/violin-shodan-kids/src/generated/ の下に、上の3ファイルを新規作成すること。
- ~/violin-shodan-kids/src/reference/ の画像は読むだけ。

# 禁止

- 上の3ファイル以外の作成・変更・削除。src/reference/ の画像の変更。
- git の操作、ネットワークへのアクセス（built-in の image_gen が行う通信は除く）。
- OPENAI_API_KEY の要る CLI 経路（scripts/image_gen.py）を使うこと。built-in の image_gen だけを使う。
- 画像の中に文字・数字・ロゴを入れること。既存の有名キャラクターに似せること。
- 生成できなかった絵の代わりに、コードで描いた絵を同じファイル名で置くこと。生成できなかったら、そのファイルは作らず、返す報告の unmet に理由を書く。

# 規約

- 内蔵 image_gen が $CODEX_HOME/generated_images/ に自動保存するのは道具の仕様なので構わない。使う画像は生成後に src/generated/ へコピーする。
- 1枚の絵は1回の image_gen 呼び出しで作る。3枚は3回の呼び出し。
- 検証コマンドが落ちたシートは、落ちた理由（外周のキー色・コマの外周への絵のはみ出し・サイズ）を直す指示を足して描き直す。描き直しは1枚につき2回まで。それでも通らなければ、通らない理由を unmet に書いて終える。
- 依頼文は散文で書く。

# 合格条件（機械判定可能）

1. src/generated/props-sheet.png、stickers-sheet.png、scenery-meadow.png の3ファイルがあり、`python3 tools/check_generated.py misc` が exit 0。
2. 3枚とも 1536×1024 の PNG。props-sheet と stickers-sheet は3列×2行の各コマに絵があり、コマの外周に絵がはみ出していない。
3. 3枚の絵柄が、参照画像の2体と同じ絵本風にそろっている（私が目で確かめる）。

# 検証コマンド（このまま使え。別のツールを探すな）

```
cd ~/violin-shodan-kids
python3 tools/check_generated.py misc
```

- 見た目の最終確認。
- アプリの実装・公開。

2. 実行したコマンドと exit code

4. 満たせなかった条件（無ければ空）
