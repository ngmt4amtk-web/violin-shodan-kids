# 仕事

私（長又）が幼稚園生向けに作るバイオリンのWebアプリ「バイオリン初段 幼稚園生版」（~/violin-shodan-kids）で、ロングトーンの画面に走るキャラクターの絵を作る。ロングトーンは、弓を4秒かけて「もと」から「さき」へ動かして音を伸ばす練習で、画面ではキャラクターが細長いコースを左から右へ4秒で走り、そのあと右から左へ4秒で戻る。この走りの絵を、3体のキャラクターそれぞれ1枚ずつ、計3枚のシートとして作る。

走らせるのは、すでにアプリにいる3体。参照画像は作業フォルダの src/reference/ にある。最初に built-in の view_image でそれぞれを開き、絵を目で確かめてから描き始める。

- ふわふわ：src/reference/fluffy-cutout-v1.png。クリーム色の丸くてちいさなこいぬ風キャラ。参照画像は3列×5行で、行が衣装の段。**2行目（赤いリボンを首につけた段）の姿**で走らせる。
- きょうりゅう：src/reference/dino-cutout-v1.png。青緑色の小さな恐竜。**2行目（オレンジのバンダナの段）の姿**で走らせる。
- いぬ：src/reference/dog-cutout-v1.png。写真のような質感の、黒い頭に茶色の頬、白い胸の小型犬。**2行目（赤い柄のバンダナの段）の姿**で走らせる。このキャラだけは写真のような質感で描く。絵っぽくしない。

作るシートの形（3枚とも同じ）：

- 画像サイズは 1536×1024 の1枚。**3列×2行の6コマ**で、1コマは 512×512。左上から右へ、次に下の段の左から右へ、走りの1周期の順に並べる。
- 全コマ、**右向き**の全身。同じ1体の同じ大きさ。左右反転はアプリ側でやるので、左向きは描かない。
- 6コマの内容は、はずむように楽しそうに走る1周期。1: 右足が前に着く。2: 体が少し沈む。3: 足が入れ替わる途中。4: 両足が地面から浮く（耳・しっぽ・リボンやバンダナが後ろへなびく）。5: 左足が前に着く。6: 足が入れ替わる途中。6→1につながるようにする。
- 足もとの高さ（地面に着く足の裏の位置）は6コマとも同じ高さにそろえる（コマの上から約430px付近）。
- 各コマの絵は、そのコマの512×512の内側に、上下左右とも24px以上の余白を残して収める。コマをまたぐ絵・次のコマにはみ出す絵は作らない。
- 背景は、全面ベタ塗りのキー色1色。コマとコマの間もキー色。グラデーション・影・地面の線・床・枠線・文字・数字・透かし・速度線・ほかのキャラクターは入れない。キー色は、ふわふわといぬは**緑 #00B140**、きょうりゅうは**マゼンタ #FF00FF**（きょうりゅう自身が青緑なので、緑だと切り抜きで崩れるため）。絵の中にキー色と同じ色は使わない。
- 参照画像と同じ個体にする。顔のつくり・目・体の比率・色・線の太さ・衣装を変えない。新しい小物（バイオリン・弓・靴など）は足さない。

出力ファイル（作業フォルダ内に新規作成）：

- src/generated/run-fluffy.png
- src/generated/run-dino.png
- src/generated/run-dog.png

# 触ってよい範囲

# 禁止

- 上の3ファイル以外の作成・変更・削除。src/reference/ の画像の変更。
- git の操作、ネットワークへのアクセス（built-in の image_gen が行う通信は除く）。
- OPENAI_API_KEY の要る CLI 経路（scripts/image_gen.py）を使うこと。built-in の image_gen だけを使う。
- 画像の中に文字・数字・ロゴを入れること。
- 生成できなかった絵の代わりに、コードで描いた絵を同じファイル名で置くこと。生成できなかったら、そのファイルは作らず、返す報告の unmet に理由を書く。

# 規約

- 内蔵 image_gen が $CODEX_HOME/generated_images/ に自動保存するのは道具の仕様なので構わない。使う画像は生成後に src/generated/ へコピーする。
- 1枚のシートは1回の image_gen 呼び出しで作る（6コマを別々の呼び出しで作ると別の個体になるため）。3枚は3回の呼び出し。
- 検証コマンドが落ちたシートは、落ちた理由（外周のキー色・コマの外周への絵のはみ出し・サイズ）を直す指示を足して描き直す。描き直しは1シートにつき2回まで。それでも通らなければ、通らない理由を unmet に書いて終える。
- 依頼文は散文で書く。

# 合格条件（機械判定可能）

1. src/generated/run-fluffy.png、run-dino.png、run-dog.png の3ファイルがあり、`python3 tools/check_generated.py run` が exit 0。
2. 3枚とも 1536×1024 の PNG で、3列×2行の各コマに絵がある。
3. 各シートがキャラクターごとの参照画像と同じ個体に見える（私が目で確かめる。Astra は参照画像と並べて自分でも確かめ、違いがあれば描き直す）。

# 検証コマンド（このまま使え。別のツールを探すな）

```
cd ~/violin-shodan-kids
python3 tools/check_generated.py run
```

- 見た目（参照画像との同一性・走りの自然さ）の最終確認。
- アプリの実装・公開。
